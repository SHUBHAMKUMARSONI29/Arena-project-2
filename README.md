## 📱 Responsive Design

The website is designed to work on:

* 💻 Desktop
* 💻 Laptop
* 📱 Tablet
* 📱 Mobile

CSS media queries automatically adjust the layout for smaller screens.

Example:

```css
@media (max-width: 768px) {
    .about-container {
        grid-template-columns: 1fr;
    }

    .projects-grid {
        grid-template-columns: 1fr;
    }
}
```
